# 效果菜单 —— 导演点单用

> 这份是**给你（导演）看的**，不是给程序看的。
> 你不需要知道实现，只要说清楚三件事，我就能落地：
>
> **哪一段**（拍 / 小节 / 秒都行，我换算）＋ **要什么效果** ＋ **大概多大劲儿**。
>
> 例：「第 2 个副歌那 8 小节，做**错峰**，一格一格亮过去，劲儿中等。」
> 我读不懂会问你，绝不会自己编一个。

⚠️ 一条铁律先记住：**每块画板必须有淡入淡出**（或者你明确说"这里要硬切"）。
这是 MV 和 PPT 的区别。

## 1. 动效（已上线，今天就能点）

| 效果 | 你会看到什么 | 你这样说 | 备注 |
|---|---|---|---|
| **缓动** | 同样一段路，快慢手感完全不同 | 「冲出去**急停**」/「**慢慢加速**」/「两头慢中间快」/「撞过头**弹回来**」 | 5 档：匀速 / 急停 / 急刹 / 两头慢中间快 / 回弹 |
| **关键帧** | 我按你说的时刻摆一串值 | 「3.2s 涨满 → 停半拍 → 4.0s 掉下去」 | 想几个节点说几个 |
| **卡拍脉冲** | 每拍"咚"一下，很快衰减 | 「每拍**闪一下**，1/10 拍衰掉」 | 用网格算，最稳 |
| **跟鼓（真实 onset）** | 不是按拍，是音频里**真的响了**才动 | 「**鼓一响**它就缩一下」/「**人声一出来**画面就亮」 | 用的是实测 onset 表，副歌才开的地方比网格准 |
| **错峰（延迟）** | 一排东西像多米诺，第 i 个晚 i×一点点才亮 | 「这一排**依次亮过去**」/「字一个一个出来」 | 每拍可以重新来一轮 |
| **拖尾** | 同一个东西在它过去的位置留几份，越旧越淡 → 彗星尾 | 「要**拖尾**，大概拖 0.2 秒」 | 便宜；拖尾是"重画过去"，不是攒画布 |
| **回声 / 残影** | 延迟重现几份，越旧越淡、越小、越偏、还能**偏色** | 「要**回声**，三份，一份比一份红」 | 示波器余晖 / 老电视残影 |
| **沿路径走** | 让点或文字**沿着一条线**爬，知道走到哪、朝哪边 | 「让这句话**沿着这条线爬**」 | 也能算出"走了百分之几" |
| **擦除** | 东西像被光/水从左到右（或中间向两边）**填满** | 「**逐字点亮**」/「从中间撑开」 | 逐词歌词就靠它 |
| **渐变** | 颜色从这头渐变到那头，或从中心化开 | 「背景从黑**渐变**到深绿」/「中心**径向**发光」 | 颜色只用调色板里的 |
| **确定性抖动 / 噪点** | 极轻微、不规律的漂移，不是正弦波那种死规矩 | 「有一点**不规律的小抖**」 | 同 seed 同帧永远一样 |
| **双关注释** | 在大字下面用小字写一行等宽**代码注释**，点出第二层意思 | 「这个词是双关，注释点一下」 | 例：`EXECUTION` 下面 `// run, or kill`。全片统一的装置 |

## 2. 画面质感（渲染时的"滤镜"，全片统一）

这一层是**整张画面的味道**，不是某个图形。默认**不开**（因为它是全片统一决定，应该由你定一次）。

| 效果 | 你会看到什么 | 你这样说 |
|---|---|---|
| **辉光 bloom** | 最亮的地方往外"糊"出一层光 | 「副歌**上辉光**」/「不要辉光，干净点」 |
| **光晕 halation** | 高光边缘泛**橙红**（胶片、玻璃、CRT 的味道） | 「要有**胶片味**」 |
| **色散 CA** | 画面边缘红蓝轻微错位 | 「**边缘**有点**散**」 |
| **颗粒 grain** | 一层细微的胶片颗粒 | 「全片一层**很轻的颗粒**」 |
| **暗角 vignette** | 四角压暗，视线收到中间 | 「**压暗四角**」 |
| **曝光 / 淡出 / 反相** | 整体变亮变暗 / 淡到黑 / 黑底白字互翻 | 「这段**越来越暗**」/「整段**反相**」 |

**代价（实测）**：同一段 12 秒素材，不开后期 110.9 帧/秒，开后期 38.6 帧/秒。
所以后期是"渲染时多花时间、但画质提升最大"的一档，值得为成片开一次。

## 4. 还没做的（想要就点，我评估成本）

| 想要的东西 | 说明 | 需要什么 |
|---|---|---|
| **歌词逐词点亮** | 每个字随唱出现/变亮 | 对齐工具已就位（`npm run align:lyrics`），**等你贴歌词文本**；只给纯文本的话时间是候选，要你听一遍 |
| **段落感** | "副歌才换配色""前奏压暗" | 段落**候选**已从音频跑出来了（`assets/sections.json`），但名字要你听一遍确认 |
| **专门字体** | 现在只有系统等宽字体，换机器可能变 | 要打包字体文件进项目（开源字体，跨机器一致） |
| **手写体文字** | 文字像被笔/光标**一笔写出来** | 需要单笔画字体 + 书写同步 |
| **真运动模糊** | 甩镜/砸字是连续拖影，不是台阶 | 已有，但**很贵**（约 ×100 成本），只给标了的段开 |
| **4K 母版** | 真 3840×2160，不是放大 | 画板要按 2 倍尺寸重画一遍，成本翻倍 |
| **片尾回放** | 结尾把每块画板各闪一张 | 需要一个"每块渲一张静帧"的工具 |

## 6. 你写策划时，时间建议用"拍"

`config/project.json` 里已定：130 BPM，第 1 拍在 **459.7ms**，一小节 4 拍 = 1846.08ms。

> 第 N 拍 = 459.7 + (N−1) × 461.52 ms
> 「第 33 拍」≈ 15.24 秒

写"第 17 小节第 3 拍"比写"31.3 秒"精确，而且我改不坏。写秒也行，我会换。
