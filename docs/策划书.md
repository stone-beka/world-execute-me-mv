## 0. 一句话立意

用一句人话说清：**这个 MV 到底在讲什么？** 不一定要有故事，但要有**一个贯穿全片的动机**。

```
一句话：ai执行爱的参数，渴望得到人类的回应，以下是解释：
ai输入参数，执行爱上人类这个任务，向他展示自身的一切（创建新世界），在这个过程里不断展示自己，给他记忆里的历史和推演的未来，它想要给这个人一切，尽管这一切都在一个模拟中（即ai离开不了这个模型），但是人不为所动，那么ai就感受不到自己作为任务执行者的存在，人离开了，ai感到孤独，缓存仍在运行，ai依旧感到孤独和难过，并认为是人类给出了爱这个非法参数，并认为如果自己抹除掉除了让人类和自己相爱的其他因素（即无关因素，它认为是其他人干扰了这个男人和自己相爱）那么这一切就能随她所愿，最后是ai的执行（不过被浪漫化了，实际上是ai想要去屠杀掉除了男主外的其他人），然而最后却只能在模拟器里存在，他们都困在了这个感情里，所以她说男主和他都trapped里，然后最后它向人说它知道爱的代数式，希望它能回来
```

## 8. 开工前自检

对着每个 SHOT 问 5 个问题：

1. **有时间吗？** 拍号、秒数、或者「某个副歌」都行——但得有。
2. **能画出来吗？** 是「屏幕上的图形/文字」吗？（本引擎是 Canvas 2D 画图形，不是实时 3D）
3. **靠什么动？** 跟时间流、跟拍、还是被某个事件触发？
4. **怎么接上一块？** 是「变过去」还是「切过去」？
5. **有没有整块只是一个形容词？** 中一条就补一张具体画面。

## 附：歌词双关对照表（导演提供 ★ 画面要结合这层理解）

歌词里大量是**编程 / 数学 / 双关**。凡是出现这些词，画面都应该让人看出第二层意思，
而不是只当普通英文单词画。下面是导演给的对照表，照抄不改。

| 词 | 字面 | 第二层（画面要结合这个） |
|---|---|---|
| `world.execute(me);` | 代码风格的方法调用（world 对象 · execute 方法 · me 参数） | execute 既是「执行」也是「**处决**」→ 「世界，执行我 / 处决我」 |
| `object creation` | 面向对象编程的「创建对象」 | 也暗指「**造物**」 |
| `parameters initialisation` | 编程术语「参数初始化」（英式拼写） | 机器在给自己填参数 |
| `simulation` | 模拟 / 模拟世界 | 暗指**虚拟现实或程序化世界** |
| `dimension` `circumference` `sine wave` `tangents` `infinity` `limitations` | 数学与几何术语 | `limitations` 双关 **limit（极限）** 与「限制」 |
| `current` `AC` `DC` | current 是电流；AC/DC 是交流/直流 | 也常被用来**暗示双性恋**，或指乐队 AC/DC |
| `A.D` `B.C` | 公元 / 公元前 | 从 A.D 到 B.C = **时间倒流** |
| `stimulations` `satisfaction` | 刺激 / 满足 | 我倾泻一切，只为换你满足 |
| `execution` | 执行 | 也可指「**处决**」 |
| `eggplant` | 茄子 | 茄子 emoji 在网络上常被用作**性暗示** |
| `F to M` `AM to PM` `S to M` | 女/男；上午/下午； | `S/M` 是**施虐/受虐**，也指**角色切换** |
| `vibrations` | 振动 | 也可指**情绪共鸣 / 氛围感应** |
| `completion` `isolation` `fragments` | 完成 / 隔离 / 碎片 | 分别对应**编程 / 数据库事务隔离 / 代码片段** |
| `illegal arguments` | 编程中的「非法参数 / 非法实参」 | 也指逻辑上「**不合法的论证**」 |
| `Ein Dos Trois Ne Fem Liu` | 混合多语言的数字计数，大致对应 1–6（德语一 / 西语二 / 法语三 / 匈牙利语四截断 / 瑞典语五 / 中文六） | 像在**模拟执行循环计数** |
| `lo-o-ove` | 把 love 拉长 | 模拟**语音合成、卡顿或故障**效果 |
| `algebraic expression` | 代数表达式 | 用**数学语言**表达「爱」 |

**实现装置（我加的，贯穿全片）**：因为是终端片子，双关一律用**等宽代码注释**点出来，
例如大字 `EXECUTION` 下面一行小字 `// run, or kill`。这样第二层意思看得见，又不破坏画面。
