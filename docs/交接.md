## 可复用的东西

### 一、引擎层（`src/core/`，与本片解耦，换个片子照样能用）

| 文件 | 能干什么 | 备注 |
|---|---|---|
| `kernel.js` | 确定性哈希 / 随机 / 平滑噪声 fbm / 缓动 | 全片唯一随机来源；禁用 `Math.random` |
| `timeline.js` | 帧 ↔ 毫秒 ↔ 拍 换算；读 config；载入 onsets / sections | 时间只认 `config/project.json` |
| `fade.js` | 淡入淡出信封 / 硬切 / 调色板工具 / `rgba()` | 每块画板必须有进出 |
| `fonts.js` | 注册打包字体（**IBM Plex Mono**，`assets/fonts/` 进 git） | 解决"换机器字就变"；`s.mono(16)` |
| `lyrics.js` | **词级歌词查询**：`get/find/wordProgress/lineCharProgress` | 按内容查，不写死秒 |
| `motion.js` | 缓动/关键帧、错峰、**拖尾回声**（闭式重算）、路径取点、渐变、擦除、onset 脉冲 | 拖尾不攒画布，所以仍可只重渲 3 秒 |
| `post.js` | **后期质感 = ffmpeg 滤镜链**（辉光/光晕/色散/颗粒/暗角） | 不在 JS 里逐像素（那样几百 ms/帧） |
| `registry.js` | 画板注册 + 给画板的 `s` 状态包 | 见 `AGENTS.md` 里的 `s` 清单 |
| `floor.js` | **常驻「地板」**：叠在画板之上的极轻、永不静止的底噪 | 保证全片 0 静止段；`config.floor` 控制，`--floor/--no-floor` 临时覆盖 |
| `render.js` | 逐帧渲染入口；**子帧运动模糊**（`samples/shutter`） | 子帧只挪 ms、`frame` 不变 → 不会双重曝光 |

## 踩过的坑（**别重复踩**）

| 坑 | 症状 | 规矩 |
|---|---|---|
| `Float32Array.from(samples.length, fn)` | 传长度数字 → 拿到空数组，静默算错 | 要传**数组**，不是 length |
| `shadowBlur` | `@napi-rs/canvas` 把描边阴影画成**填充盘** | 辉光一律"叠几层"，别用滤镜/阴影 |
| `Path2D` | `is not defined` | 要用得从 `@napi-rs/canvas` import；或直接用 ctx 路径 |
| 中文写进画面 | 渲染成 ▯▯▯（且跨机器不同） | 画面**只用 ASCII**，或用打包字体（现在只有拉丁） |
| 环形弧 `a → a+2.3π` | 扫过 414° > 一圈，缺口被糊掉 | 弧度要算真：`2π − gap` |
| 立方体点阵 `side=18` + 320 点 | 全挤在第一层，变成一根柱子 | 维数要和点数匹配（7³=343） |
| 已删对象用固定进度 `shatter` | 每个死对象留一圈红环，糊一屏 | 删干净就直接不画 |
| 行尾留"气口"40ms | 每两句之间闪一帧空隙界面 | 画面区间**首尾相接**；"在唱"与"占画面"分成两个字段 |
| `L.find(q)[0]` | 抓到**第一处**匹配（可能在前一段） | 要限定范围，或挑唯一词 |
| `preview --video` | **没音轨**（判断同步只能靠猜） | 已补：默认混音轨，`--no-audio` 关 |
| `-map` 排在第二个 `-i` 前 | 有后期+有音轨时 ffmpeg 提前退出（EPIPE） | ffmpeg 参数：**先排完所有输入，再排输出选项** |
| `gap-check` 全片无空洞 | `toRuns([])` 推出 `[undefined,undefined]` → 假报一个 NaN 空洞 | 已修（空数组返回空） |
| 一个画板语法错 | **所有**画板都加载失败 | 改完立刻 `--only 那块` 试一下 |
| `--jobs >1` | mp4 不逐字节相同（各片 GOP/码率独立） | 像素一致；要字节级复现用 `--jobs 1` |
| PowerShell `-replace \| Set-Content` | 非 ASCII 字符被**双重编码**（UTF-8 被当 ANSI 重写，破折号变 `U+9225 U+003F`） | 批量改文本用 Edit/Write 工具，别用 PowerShell 管道 |
| 只验证「画板注册了」 | 一个每块画板都在抛异常的版本，覆盖率照样报 100% | `verify:ink` 数的是真实图元（用 `lib/record-ctx.js` 包住真 ctx） |
| 只验证「不是空帧」 | 画了 0.6s 一模一样的东西 = 观众看到的「卡住」，空帧检查抓不到 | `verify:gap` 的运动层比对逐像素指纹，报静止段 |
